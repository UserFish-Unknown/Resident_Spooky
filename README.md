A first-person horror game set across five days of an ordinary routine. The player wakes in a studio apartment, walks to work, completes small tasks, and returns home to sleep. Each day the routine stays the same while strange details creep in: flickering lights, unsettling phone calls, footsteps, TV static that turns to music, and a shadow figure that watches from a distance. A voice insists everything is normal. Stay on track, and don't look too closely.

Built in Unity with three scenes: Home, Street, and Office, each full of dynamic objects and interactions.
